# 🎃 Rutas de los Dulces – Android

Aplicación móvil desarrollada en **Kotlin** para Android, diseñada para que niños, familias y comunidades puedan descubrir y explorar lugares que entregan dulces durante Halloween.

El proyecto incorpora una interfaz moderna inspirada en **Liquid Glass**, combinando transparencias, degradados, bordes translúcidos y una temática visual de Halloween.

## 🚀 Características

- 🎃 Landing page temática de Halloween.
- 💎 Interfaz moderna con estilo Liquid Glass.
- 🗺️ Integración de OpenStreetMap mediante osmdroid.
- 📍 Geolocalización GPS del dispositivo.
- 👻 Marcador para visualizar la ubicación del usuario.
- 🍬 Navegación entre las secciones principales.
- 📱 Aplicación nativa desarrollada en Kotlin.
- 🐧 Compilación mediante Gradle desde Ubuntu.

## 🛠️ Tecnologías

- **Kotlin** – Desarrollo Android.
- **Android SDK** – Plataforma móvil.
- **OpenStreetMap + osmdroid** – Mapas interactivos.
- **Android LocationManager** – Geolocalización GPS.
- **Gradle** – Gestión de dependencias y compilación.
- **XML** – Recursos y estilos visuales.

## 🔮 Próximas funcionalidades

Crear una experiencia interactiva y accesible que facilite encontrar lugares para pedir dulces durante Halloween, aprovechando mapas, geolocalización y tecnologías móviles modernas.
